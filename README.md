# The_Syntax_Surgeon.ipynb
The Syntax SurgeonAI-Powered Code Fixer & Conversational AssistantThe Syntax Surgeon is an intelligent platform that leverages IBM's Granite 3.3 2B Instruct model to provide a seamless blend of conversational AI and advanced Python code repair. It addresses the need for accessible programming assistance by operating without external API keys and offering local model deployment.## Key FeaturesConversational AI: Engaging, context-aware dialogue powered by the state-of-the-art Granite 3.3 2B model.Automatic Code Detection: Uses advanced regex patterns to identify Python functions, classes, and logic within chat.Intelligent Code Fixing: Automatically corrects indentation, balances brackets, and normalizes line endings.Professional Formatting: Integrates with Black and autopep8 to ensure code follows PEP 8 standards.Document Export: Capability to export complete conversation histories in PDF or TXT formats.Privacy-Focused: Runs locally on your infrastructure (or Colab), ensuring sensitive code remains private.## Technical ArchitectureThe system is built with a modular approach, separating the user interface from the heavy-lifting AI and analysis engines.Frontend: Gradio 4.0+ for a modern, responsive web interface.Model: IBM Granite 3.3 2B Instruct (via Hugging Face Transformers).Analysis: Python AST module for deep syntax validation and error reporting.Execution: PyTorch-based inference optimized for GPU (CUDA) or CPU.## Getting Started### PrerequisitesPython 3.8+ Google Colab (Recommended for free T4 GPU access) Required Libraries: gradio, transformers, torch, black, autopep8, reportlab ### InstallationClone the repository (if applicable) or create a new Python file named the_syntax_surgeon.py.Install dependencies:Bashpip install gradio transformers torch black autopep8 reportlab requests
Run the application:Pythonpython the_syntax_surgeon.py
## Usage ScenariosDeveloper Assistance: Paste broken snippets to get instant fixes and explanations.Learning & Tutoring: Students can ask coding questions and receive personalized tutoring based on chat history.Code Review: QA teams can use the tool to quickly format pull requests and check for common Python mistakes.## Project Roadmap (Future Enhancements)Support for additional languages like JavaScript, Java, and C++.Integration with IDE plugins (VS Code/PyCharm).Voice input and output capabilities for hands-free assistance.Real-time streaming responses for a faster chat experience.
